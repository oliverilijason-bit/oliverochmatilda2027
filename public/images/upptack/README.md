# Bildplatser för Upptäck området

Filerna i den här mappen är dekorativa placeholders. Ersätt dem med egna bilder och
uppdatera motsvarande `image`-sökväg i `src/pages/upptack-omradet.astro`.

- `hero.svg` – stor herobild, rekommenderat format 16:9
- `mat-fika.svg` – frukost, café eller fika
- `natur.svg` – Ringsjön, promenad eller natur
- `utflykt.svg` – en lokal plats eller sevärdhet
- `bad.svg` – sjö eller badplats

Vanliga format som `.jpg`, `.webp` och `.avif` fungerar bra. Om filändelsen ändras
behöver även sökvägen i Astro-filen ändras.
